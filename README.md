# Норма — конструктор инструкций для учреждений культуры

Локальное веб-приложение для подготовки **проектов** должностных инструкций, инструкций по охране труда и о мерах пожарной безопасности для учреждений культуры РФ и ЛНР.

## Запуск

Установите Node.js 20+ и в каталоге `instruction-studio` выполните:

```bash
npm start
```

Откройте http://localhost:3210. Зависимости устанавливать не требуется. Данные и архив созданных документов хранятся в localStorage браузера. Для переноса нормативной базы используйте экспорт/импорт JSON (архив и данные формы при этом не переносятся). Для проверки кода: `npm test`.

## Доступ для других пользователей

**В интернете:** опубликуйте этот каталог как отдельный репозиторий GitHub, подключите его к Render через **New → Blueprint** и выберите `render.yaml` в корне репозитория. Render сам установит Node.js 22, запустит `npm start`, проверит `/health` и выдаст публичный HTTPS-адрес вида `https://norma-instruction-studio.onrender.com`. Передавайте пользователям выданный Render адрес; установка программы на их компьютерах не нужна. Реальный адрес определяется после развёртывания. Ресурсы бесплатного тарифа Render могут «засыпать» при неактивности.

**В одной локальной сети:** запустите сервер с `HOST=0.0.0.0` и передайте людям локальный IP компьютера с портом 3210. Для PowerShell:

```powershell
$env:HOST = '0.0.0.0'
npm start
```

Пользователи должны находиться в одной сети, а сетевой доступ к порту 3210 должен быть разрешён. Не пересылайте ссылку `localhost:3210` другим людям — она работает только на вашем компьютере.

У каждого браузера **свои** черновики, архив и подтверждения правовых актов. Сервер не имеет учётных записей и не хранит документы пользователей. Очистка данных браузера удалит архив: скачивайте важные версии в DOCX и экспортируйте нормативную базу в JSON.

Выберите шаблон — заголовок и состав разделов в предпросмотре сразу меняются. Должность можно выбрать из подсказок или ввести вручную. Укажите территорию и год через дату утверждения; календарь не ограничен конкретным годом. После заполнения обязательных полей нажмите «Создать инструкцию»: снимок проекта появится в архиве. Кнопка «Скачать Word (.docx)» формирует настоящий Word OpenXML-документ; из архива можно скачать версии прошлых лет. HTML и печать/PDF также доступны. Для проверки интерфейса в Edge/Chromium можно открыть отдельное окно с `--remote-debugging-port=9238` по адресу приложения и выполнить `node browser-smoke.mjs`.

На Windows с установленным Microsoft Word можно дополнительно проверить открытие созданного файла командой `node word-compat-smoke.mjs`.

## Обновления законодательства

Кнопка «Проверить сейчас» получает **только** две заранее заданные официальные страницы: портал опубликования правовых актов РФ и реестр Народного Совета ЛНР. Сервер вычисляет отпечаток текста страниц, браузер сравнивает его с предыдущим успешным снимком. Наличие изменений означает, что страницу нужно просмотреть; это не подтверждение принятия или вступления акта в силу. При недоступности сайта отображается ошибка, успешный прошлый снимок сохраняется. Ссылки на источники доступны из интерфейса.

Базовый перечень актов **не подтверждён как действующий** и служит исключительно подсказками для поиска. Такие записи не попадают в инструкции. Встроенная запись о законе ЛНР № 299-I исключена: факт публикации поправки не равен проверке актуальной редакции основного закона и применимости к инструкции. Старые пользовательские записи после обновления также считаются непроверенными до новой явной отметки.

После проверки **конкретной** официальной публикации специалист задаёт статус «Проверен и действует», ссылку на сам акт, начало действия и дату проверки. Для применения федерального акта в ЛНР отдельно отмечается проверенная применимость в ЛНР. Акт включается в новый проект только для выбранного типа инструкции, территории и даты в указанном пользователем диапазоне действия. Отменённые и непроверенные акты не включаются. Программа не умеет самостоятельно подтвердить последующие изменения или редакцию, действовавшую в прежние годы: при повторном использовании архива проверьте историческую редакцию. Базовый список неполон и не подменяет локальные приказы, результаты СОУТ, оценку рисков, паспорт здания и план эвакуации.

Программа не отправляет данные учреждения на внешние сайты; файлы Word создаются прямо в браузере, а сервер запрашивает только страницы источников по кнопке. Архив зависит от хранилища текущего браузера и его лимита: скачивайте важные документы в `.docx` для долговременного хранения. Для PDF используйте системную печать.
